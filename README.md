# TV A CRÍTICA 3D

Protótipo de jogo 3D web da emissora TV A Crítica, feito para rodar no navegador e ser publicado pelo GitHub Pages.

## Versão inicial

A primeira versão inclui:

- movimentação em primeira pessoa;
- fachada da emissora;
- recepção;
- corredores;
- salas iniciais dos programas;
- Switcher Master inicial;
- iluminação e sinalização 3D;
- estrutura preparada para receber os cenários aprovados individualmente.

## Controles

- Clique em **Entrar na emissora** para capturar o mouse.
- `W`, `A`, `S`, `D`: movimentação.
- Mouse: olhar ao redor.
- `Shift`: andar mais rápido.
- `ESC`: liberar o mouse.
